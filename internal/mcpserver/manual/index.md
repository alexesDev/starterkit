# Index

Topics are short and one concern each: read only the ones the task needs. Whoever adds a topic keeps it that way, and splits a long one into two that link to each other.

Read a topic with `instructions(topics=["name"])`, several at once with up to five names, or search every topic with `instructions(query="words", query_op="and")`, where `query_op` is `and` (every word, the default), `or` (any word) or `exact` (the phrase).

| When | Topic |
|---|---|
| You are new here, or need the shape of the API | overview |
| You need a field, a type or an argument name | graphql_introspection |
| You are about to read data | graphql_query |
| You are about to change something | graphql_mutation |
| A call failed, or a document was refused | errors |
